# Garmo — oleh Solo Creative

Installer dan update rasmi **Garmo**: mockup jersi dari Illustrator ke Photoshop, dengan preview pantas dalam app.

## Muat turun
Lihat [Releases](https://github.com/MSyaraff/Garmo-Releases/releases/latest):
- **Mac (Apple Silicon)**: `Garmo-Mac.zip` → buka → klik kanan `Pasang Garmo.app` → Open
- **Windows 10/11 x64**: `Garmo-Setup.exe`

Satu pemasangan memasang app Garmo dan panel Illustrator (Window → Extensions → Garmo).

## Update
App Garmo menyemak `mac/latest.json` dan `windows/latest.json` dalam repo ini. Setiap update ditandatangan secara digital dan disahkan oleh app sebelum dipasang.
